Corrections given while planning the orchestration system (2026-08-27):

1. **The `opsx`/`openspec-*` skills are official `@fission-ai/openspec` tooling** (generated by `openspec init/update --tools claude`), not beatpath-specific — always use them for spec/artifact authoring; never reinvent that layer.
2. **No Entire** (`.entire/`, `plugins/entire.ts`, `entireSessionId`): mdv is replacing it with his own observability solution (v1 = hub-native `metadata.runLog`; deeper session capture to be designed).
3. **agent-kit stays multi-tool**: never delete the opencode/pi/cursor skills from `mdvacula/agent-kit` when adding Claude Code assets — organize per-tool, retain everything.
4. **GitHub Actions that spin up coding agents** (agent-kit's sync-template/sync-hub pi builders) are distrusted — disable them before pushing anywhere they could fire; they can overwrite directly-edited repos.

**Why:** these came as explicit mid-plan corrections; 2–4 all reflect the same stance as [[no-headless-claude-automation]] — no unattended agents, own the tooling.
**How to apply:** when touching agent-kit, mcp-task-hub, or any openspec repo, check these before restructuring or wiring automation.
